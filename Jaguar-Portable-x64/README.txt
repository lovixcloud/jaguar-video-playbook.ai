Jaguar Studio - Portable Edition (x64)
======================================

Jaguar Studio is a native Windows application for screen recording, webcam capture, audio recording, video timeline editing, and video export.

To run Jaguar Studio Portable:
Double-click Jaguar.exe in this folder.

All project settings and temporary cache files will be kept local to this folder or standard user directory without system registry changes.

Product: Jaguar Studio
Executable: Jaguar.exe
Project Extension: .jaguar
Version: 1.0.0
